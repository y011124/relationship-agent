# 五分钟演示与岗位表达

全部使用合成人物与经历，不展示私人聊天或Key。

1. 业务问题（30秒）：关系对话经常跨会话、涉及多个人；用户反复交代背景，模型容易把猜测写成事实。
2. 核心Demo（90秒）：创建小林/阿泽；记录一次临时取消约会；确认后在新会话回忆；切换阿泽证明人物范围；手动纠正后再次提问。
3. 工程解释（60秒）：账号+人物过滤、来源类型、确认写入、检查点、幂等与租约；并非为每个人启动Agent。
4. 故障演示（30秒）：用测试注入模型失败，恢复时路由不再调用；通过trace观察阶段，展示预算计数不重置。
5. 评测和权衡（60秒）：40个中英文场景、两种记忆变体、越权测试；区分自动化通过与人工质量评分。说明词项检索、保守上下文失效与小规模串行事务的取舍。
6. 交付状态（30秒）：展示部署/备份材料及已经验证的部分。公网和真实用户未完成前明确说仍待验证。

简历可使用的准确表述：独立实现带人物记忆的关系交流Agent原型；构建多用户授权、可确认记忆、可恢复工作流、模型调用预算与评测基础设施。只有部署并测评后，才能添加在线用户规模、满意度、成本降低或延迟改善等数字。
